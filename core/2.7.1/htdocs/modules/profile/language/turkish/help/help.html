Yardım: Profil

-----Yardım İçeriği ----------

AÇIKLAMA

Profil modülü, özel kullanıcı profili alanlarını yönetmek içindir.

YÜKLE/KALDIR

Özel bir önlem gerekmez, standart kurulum sürecini izleyin – /profile klasörünü ../modules dizinine çıkarın. Modülü Yönetici -> Sistem Modülü -> Modüller yoluyla yükleyin.

Modüllerin kurulumuna ilişkin ayrıntılı talimatlar şurada mevcuttur: XOOPS Kullanım Kılavuzu

KULLANIM TALİMATLARI

Bu modülü kurmak için yapmanız gerekenler:

  • Modül (bkz. 'Tercihler') ve kullanmayı planlıyorsanız isteğe bağlı olarak Profil bloğu (bkz. 'Bloklar') için tercihlerinizi yapılandırın.
  • Mevcut Kategorileri düzenleyin veya yenilerini ekleyin.
  • Mevcut Alanları düzenleyin veya yenilerini ekleyin. Burada hangi alanların hangi kategoride görüneceğini ve kullanıcı kaydı sırasında görünüp görünmeyeceğini belirleyebilirsiniz.
  • Kayıt adımlarının sırasını tanımlayın.
  • Ve son olarak, bireysel alanlar için izinler ayarlayabilirsiniz; hangileri düzenlenebilir, hangileri aranabilir.

Anti-Spam önlemleri

Spam kayıtlarını en aza indirmek için aşağıdakileri yapın:

  • Yönetici'de Koruyucu modülüne gidin, Tercihler'e gidin ve ardından en altta şu seçeneğe gidin: "Forum Spamını Durdur" POST verilerini www.stopforumspam.com veritabanına kayıtlı spam gönderenlere karşı kontrol eder.
    "IP'yi yasakla (sınır yok)" olarak ayarlayın

  • /class/captcha/config.php dosyasında, modun "metin" olarak ayarlandığından emin olun:

    return $yapılandırma = dizi(
    'devre dışı' => yanlış, // CAPTCHA'yı devre dışı bırak
    'mode' => 'text', // varsayılan mod, 'text', 'image', 'recaptcha'yı seçebilirsiniz(api anahtarı gerektirir)
    'isim' => 'xoopscaptcha', // captcha adı
    'skipmember' => doğru, // Üyeler için CAPTCHA kontrolünü atla
    'maxattempts' => 10, // Her oturum için maksimum deneme sayısı
    );

  • Profil modülünde Yönetici'ye gidin ve şu konumda bulunan Temel adıma gidin:
    /modules/profile/admin/step.php?id=1
    "Durduktan sonra kaydet" seçeneğini "Hayır" olarak ayarlayın


  • Profil Tercihlerinde, "İkinci Kayıt adımından sonra Captcha'yı kullan" Seçeneğini "Evet" olarak ayarlayın (varsayılandır)
